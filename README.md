# COPD Digital Twin (Course Project)

An interactive demo combining a simple evolving patient "digital twin" with
a trained ML model (Random Forest / XGBoost) that predicts lung function
(FEV1) and simulates future/what-if trajectories.

**This is a course project using a fully synthetic dataset. It does not
predict real COPD outcomes and is not a medical or diagnostic tool.**

See `notes/architecture.md` for the design, `notes/antigravity_brief.md`
before generating any code, `notes/data_dictionary.md` for the dataset,
and `notes/api_contract.md` for the backend API.
